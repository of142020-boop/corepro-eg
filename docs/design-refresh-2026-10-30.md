# تحديث هوية واجهة كور برو

تجديد الرئيسية والتصميم المشترك بهوية هندسية: كحلي وأزرق سماوي، وأزرار برتقالية. يستهدف التحديث وضوح اختيار الخدمة والتواصل على الهاتف، مع الحفاظ على محتوى الخدمات وبيانات السيو.

## التغييرات

- هيدر زجاجي ثابت بالشعار الحالي، وتصفح واضح للخدمات والمزيد، وقائمة هاتف تدعم Escape والتركيز ولوحة المفاتيح.
- رسم SVG أصلي توضيحي للكور بدلاً من صورة الشعار الكبيرة في الهيرو، وإزالة preload الصورة التي لم تعد مستخدمة.
- شبكة Bento للخدمات الأربع، ومراجعة متطلبات العمل وخطواته، ومدخل لسابقة الأعمال الحالية.
- نموذج واتساب مبدئي يختار القسم الصحيح: الشفاطات 01015218216، وقص/كور الإسكندرية 01094496839، وباقي الطلبات 01021507462. المستخدم يراجع الرسالة ويرسلها داخل واتساب؛ لا توجد رسالة نجاح وهمية أو أسعار أو أرقام مشروعات مختلقة.
- توحيد الفوتر وأزرار التواصل والخطوط والألوان وبطاقات الصفحات الداخلية، دون حذف محتوى الخدمات أو جدول التواصل والمناطق والأسئلة.
- إصلاح تعريفين قديمين للأنواع في مكوّن المدونة: مصدر SanityImageSource الصحيح، واستنتاج نوع دالة البيانات بدلاً من مرجع Metadata غير المعرف. لا يغير ذلك سلوك العرض.

## التحقق

- بناء الإنتاج ناجح باستخدام نسخة الإعدادات الملتزمة بالمستودع، مع إبقاء تعديل إعدادات المستخدم المحلي مستقلاً.
- `npm run seo:check`: 64 صفحة عامة، صفر أخطاء في العناوين وH1 والبيانات المنظمة وروابط الصور والصفحات والمراسي والأرقام المخصصة.
- مقارنة Title وH1 والوصف وCanonical مع الموقع الحي قبل النشر: 64 صفحة، صفر اختلافات.
- فحص Astro/TypeScript: 103 ملفات، صفر أخطاء. توجد ملاحظات استيرادات قديمة في المشروع؛ لم تعالج بإعادة كتابة ملفات غير مرتبطة بالتصميم.
- اختبار نموذج الطلب لجميع تركيبات الخدمات الأربع والمناطق الثلاث: 12 حالة ناجحة، بأرقام tel وWhatsApp متطابقة وترميز عربي صحيح، دون إرسال رسائل.
- معاينة الرئيسية على الكمبيوتر والهاتف؛ وفحص الكور والمنشار والواير والإسكندرية بعرض 320px، والشفاطات بعرض 390px، دون تمرير أفقي للصفحة، ومع الحفاظ على الأرقام المخصصة.

لا يتضمن التحديث تغييرات على العناوين أو الأوصاف أو الروابط الأساسية أو وعوداً بتحسين الترتيب بمجرد تغيير الواجهة.
